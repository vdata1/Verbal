```
START=6000 TOTAL=4000 WINDOWS=16 WORKERS=40 GEN_BUDGET=28800 CHUNK=100 \
  CONFIG=config/fullcorpus.yaml PY=python3 OUTDIR=results/regen_6000 \
  analysis/eval_help_scripts/scoped_run.sh
```

Flow: 16 parallel gen drivers over disjoint 250-row sub-windows → barrier →
adapter once → single eval @ 40 workers → one headline. Gen and eval do NOT overlap.

**Check on it:**
```bash

tail -f results/regen_6000/scoped_run.log                       # phases + live eval counter
grep -hc '^\[regex_' results/regen_6000/drive_*.log | paste -sd+ | bc   # gen rows done /4000
```

- **Done** when the log ends `=== scoped_run end …` and

**⚠️ Timing watch.** At the 36-min mark only ~219/4000 rows had generated (~2.6
min/row, slower than the rehearsal's ~0.7). If that rate holds, generation ~11h and
will hit the **8h GEN_BUDGET ceiling**, so each driver time-boxes ~74% through its
sub-window and eval runs on whatever completed (partial window, honestly labeled
`complete: false` — not broken, just short). Generation is ~1 core/driver and the box
has 48 cores, so it is NOT core-bound — more windows = faster wall-clock. If you want
fuller/faster coverage, it's **resumable** (chunks keyed by global start, completed
ones skipped): `docker kill regen_6000 && docker rm regen_6000`, then relaunch the
same command with `WINDOWS=32` (and reuse `OUTDIR=results/regen_6000`).
