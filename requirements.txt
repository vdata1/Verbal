# Python dependencies.
#
# Fandango is not installed from PyPI. The pipeline needs two small additions to
# upstream Fandango -- a customizable tree search and surrogate-permitting
# encode/decode -- supplied as patches/fandango-verbal.patch (21 lines, 2 files)
# against the pinned upstream commit below. Requires Python >= 3.11.
#
#   git clone https://github.com/fandango-fuzzer/fandango.git fandango
#   git -C fandango checkout 01be7a03de16f3dfbd95fb1596884245b5f333e3
#   git -C fandango apply ../patches/fandango-verbal.patch
#   pip install ./fandango
#
# Installed non-editable: the build uses scikit-build-core, whose editable mode
# needs extra configuration and buys nothing here.
#
# The node/bun/deno engine versions are not Python dependencies but are part of
# the experimental environment. The pins that produced the reported results are
# node v26.5.0, bun 1.3.14, deno 2.9.1. The Docker image installs exactly these
# and verifies them at container start (docker/assert_engine_versions.py).
# Outside Docker they are PATH lookups, so a bare-metal run must put these
# versions first on PATH.

PyYAML==6.0.3
